# RUNBOOK: articles_code

Версия: см. `VERSION`. Разделы фиксированные по handbook `standards/09-docs.md`. Это репо демо-кода, а не
сервис: эксплуатационные разделы «не применимо», запуск каждого демо — в его собственном `RUNBOOK.md`.

## 1. Назначение

Публичный код к статьям bigdataschool.ru, чтобы читатель поднял стенд у себя. Успех: у каждой статьи
с демо есть каталог, README со ссылкой на статью, RUNBOOK и строка в оглавлении.

## 2. Архитектура

Стадия `wiki-code` плагина bds-wiki пишет демо в `~/work/wiki/<slug>/`, прогоняет его через
`selfcheck.sh` (локально, не коммитится) и пушит в `wiki/<slug>/` этого репо. Статья ссылается на
каталог через `[github_banner url=".../tree/main/wiki/<slug>"]`.

## 3. Карта файлов на хосте

Рабочая копия: `~/work/articles_code`. Черновики демо: `~/work/wiki/<slug>/`.

## 4. Секреты

Не применимо: секретов в репо нет и быть не должно (публичный). Pre-commit хук gitleaks:
`git config core.hooksPath .githooks`. Демо-пароли стендов из текста статей (например `peerdb_demo_pass`
для localhost) внесены в исключения `.gitleaks.toml`.

## 5. Данные и БД

Не применимо. Датасеты демо генерируются скриптами в каталоге демо.

## 6. Деплой

`git push` в `main`. Публикация на сайт — отдельно, через статью.

## 7. Мониторинг и алерты

Не применимо: задач по расписанию нет. Целостность структуры проверяют `ops/selfcheck.sh` и CI.

## 8. Ежедневное сопровождение

Не применимо.

## 9. Ручная проверка step-by-step

| Шаг | Команда | Ожидаемый результат |
|---|---|---|
| 1 | `ops/selfcheck.sh` | все строки `OK` |
| 2 | открыть `wiki/<slug>/README.md` | ссылка на статью ведёт на живую страницу |
| 3 | пройти `wiki/<slug>/RUNBOOK.md` на чистой машине | вывод совпадает с приведённым в статье |

## 10. Новый хост

`git clone git@github.com:BigDataSchoolRU/articles_code.git ~/work/articles_code`.

## 11. Аварии

| Симптом | Причина | Действие |
|---|---|---|
| Читатель пишет, что код не запускается | версия зависимости уехала | пин в первой строке файла; обновить демо вместе со статьёй |
| `airflow_course/*/07_dask_yandex.py` не компилируется | в файле склеены две версии DAG (остаток после `return`) | известная ошибка, исправлять вместе с уроком 7; в CI — явное исключение |
| В git попал секрет | — | ротировать немедленно (репо публичный), затем чистка истории по handbook `standards/05` |

## 12. Шпаргалка

```sh
ops/selfcheck.sh
git ls-files wiki | cut -d/ -f2 | sort -u | wc -l     # сколько демо
```
