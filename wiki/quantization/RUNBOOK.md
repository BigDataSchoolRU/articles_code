# RUNBOOK: сравнение квантований одной модели через Ollama

Демо к статье [Quantization](https://bigdataschool.ru/wiki/quantization/) на bigdataschool.ru.
Сравнивает три GGUF-варианта одной и той же модели (4-битный, 8-битный и 16-битный) по размеру
файла и скорости генерации на локальной машине, без GPU и без облака.

## Окружение

- Ollama 0.32.13 или новее, слушает `http://localhost:11434` (проверка: `ollama --version`,
  `curl -s http://localhost:11434/api/tags`).
- Python 3.12, пакет `ollama` (python-клиент) версии 0.6.2 или новее:
  `pip install ollama`.
- Свободное место на диске: около 2 ГБ под три варианта модели.
- GPU не нужен, демо рассчитано на CPU-инференс.

## Шаг 1. Скачать три варианта модели

```bash
ollama pull qwen2.5:0.5b-instruct-q4_0
ollama pull qwen2.5:0.5b-instruct-q8_0
ollama pull qwen2.5:0.5b-instruct-fp16
```

Успех: каждая команда заканчивается строкой `success`. Проверить, что все три варианта на
месте:

```bash
ollama list | grep qwen2.5:0.5b-instruct
```

В выводе должны быть три строки с разными тегами и разным размером в столбце `SIZE`.

## Шаг 2. Запустить сравнение

```bash
python3 quant_bench.py
```

Скрипт на одном и том же промпте вызывает каждый вариант модели дважды (холодный вызов сразу
после переключения модели, тёплый — сразу за ним) и печатает размер модели, скорость в
токенах в секунду и сам ответ.

Успех: скрипт доходит до `=== СВОДНАЯ ТАБЛИЦА ===` и печатает три строки с числами, ни одна
из которых не `0.0`.

## Если не так

- **`model not found` / `manifest unknown` при `ollama pull`.** Тег модели могли переименовать
  в библиотеке Ollama. Проверьте актуальный список тегов на странице модели в Ollama Library.
- **`ollama.list()` не находит модель в `quant_bench.py`.** Имя в коде должно совпадать со
  столбцом `NAME` из `ollama list` побуквенно, включая тег после двоеточия.
- **Скорость нестабильна между запусками.** На время генерации влияет то, что ещё делает
  Ollama в фоне (выгрузка предыдущей модели из памяти, планировщик macOS). Для честного
  сравнения гоняйте демо на простаивающей машине и смотрите на порядок величины, а не на
  вторую значащую цифру.
- **Модель не выгружается между вызовами и тёплый вызов первого тега на самом деле холодный.**
  Ollama по умолчанию держит недавно использованную модель в памяти около 5 минут
  (`OLLAMA_KEEP_ALIVE`); если между прогонами скрипта проходит больше времени, первый вызов
  снова будет с полной загрузкой весов — это ожидаемо и не ошибка демо.
