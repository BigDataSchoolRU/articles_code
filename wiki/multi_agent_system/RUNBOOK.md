# RUNBOOK: мультиагентная система на LangGraph и Ollama

Пошаговый прогон демо к статье. После каждого шага указано, что должно быть в выводе.

## Окружение

- Python 3.12
- langgraph 1.2.11, langchain-core 1.5.4, langchain-ollama 1.1.0
- Ollama 0.32.9, модель qwen2.5:7b, адрес по умолчанию http://localhost:11434
- Около 6 ГБ свободной памяти под модель

Все команды даны для локальной машины. Если Ollama работает на другом хосте, подставьте свой адрес в переменную `OLLAMA_HOST`.

## Шаг 1. Окружение Python

```bash
python3 -m venv .venv
./.venv/bin/python3 -m pip install --upgrade pip
./.venv/bin/python3 -m pip install "langgraph==1.2.11" "langchain-ollama==1.1.0"
```

Проверка: `./.venv/bin/python3 -m pip list | grep langgraph` печатает `langgraph 1.2.11`. Если пакет не найден, вы запустили системный питон вместо интерпретатора из venv.

## Шаг 2. Ollama и модель

```bash
ollama --version
curl -s -m 5 http://localhost:11434/api/tags
ollama pull qwen2.5:7b
```

Проверка: `curl` возвращает JSON со списком моделей, а после `pull` в нём есть `qwen2.5:7b`. Пустой ответ или `connection refused` означают, что сервис Ollama не запущен.

## Шаг 3. Мультиагентная система с супервизором

```bash
./.venv/bin/python3 supervisor_demo.py
```

Проверка: в блоке «Маршрут» видно четыре решения диспетчера, дальше идут находки поисковика с кодом курса, рекомендация аналитика одним абзацем и вердикт контролёра, начинающийся с ОК. Прогон занимает около минуты, это нормально для локальной модели на 7 миллиардов параметров.

## Шаг 4. Сравнение цены

```bash
./.venv/bin/python3 cost_compare.py
```

Проверка: печатаются два блока с числом токенов и временем. У команды из трёх агентов токенов больше, чем у одного агента. Абсолютные числа у вас будут другими, важно соотношение.

## Если не так

- **Ответ агента обрывается или уходит в другой язык.** Свойство небольших локальных моделей, особенно на длинных цепочках. Помогает более жёсткий системный промпт или модель побольше, например llama3.1:8b.
- **Контролёр даёт ложную ошибку.** Тот же корень: агент-проверяющий сам является языковой моделью и ошибается. В продакшене проверку кодов делают обычным кодом, а не моделью.
- **Диспетчер повторяет одну и ту же роль.** Ровно тот случай, ради которого в демо стоит детерминированный предохранитель и лимит шагов.
- **`ModuleNotFoundError: langgraph`.** Запущен не тот интерпретатор, используйте полный путь до `.venv/bin/python3`.
