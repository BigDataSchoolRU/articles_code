# Медальонная архитектура (Medallion Architecture)

Код к статье [Медальонная архитектура (Medallion Architecture)](https://bigdataschool.ru/wiki/medallion_architecture/).

Демо показывает механику паттерна на одном локальном файле DuckDB, без внешней инфраструктуры:
сырой приём заказов в Bronze без валидации, идемпотентный upsert в Silver через `MERGE INTO` по
естественному ключу и полный пересчёт витрины в Gold.

## Состав

| Файл | Что внутри |
|---|---|
| `bronze_silver_gold_demo.py` | Полный прогон трёх слоёв: ингест батча в Bronze, дедуп и валидация при переходе в Silver, повторный прогон того же батча для проверки идемпотентности, второй батч с апдейтом и новым заказом, пересчёт Gold |
| `RUNBOOK.md` | Пошаговое воспроизведение с ожидаемым выводом на каждом шаге и типовыми граблями |

## Окружение

Python 3.12+, `duckdb` 1.5.5. Оператор `MERGE INTO` доступен начиная с DuckDB 1.4.0 LTS, здесь
зафиксирована версия со стенда, на котором прогонялось демо.

## Как запустить

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install duckdb==1.5.5
python3 bronze_silver_gold_demo.py
```

Подробности по каждому шагу и ожидаемый вывод — в `RUNBOOK.md`.
