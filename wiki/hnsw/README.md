# HNSW

Код к статье [HNSW](https://bigdataschool.ru/wiki/hnsw/).

HNSW (Hierarchical Navigable Small World) это графовый индекс приближённого поиска ближайших
соседей. Демо строит его на эталонной реализации hnswlib от авторов алгоритма и на FAISS
`IndexHNSWFlat` и меряет на 100 000 синтетических векторов размерности 128: как векторы
распределяются по слоям графа, как `ef` меняет recall и латентность, во что обходится рост `M`,
почему фильтр после поиска теряет строки и как работает удаление пометкой. Эталон для recall
считается точным перебором.

## Состав

| Файл | Что делает |
|---|---|
| `requirements.txt` | `hnswlib==0.8.0`, `faiss-cpu==1.15.1`, `numpy==2.5.4` |
| `data.py` | синтетические данные (смесь 200 гауссовых кластеров с внутренней размерностью 32, seed 42), атрибут для фильтра, эталон top-10 точным перебором, функция recall@10 |
| `hnsw_demo.py` | сценарии `all`, `levels`, `ef_sweep`, `m_sweep`, `filter`, `delete` |
| `RUNBOOK.md` | пошаговый прогон с ожидаемым выводом |

## Окружение

Python 3.10 или новее, компилятор C++ (`g++` или `clang++`): под Python 3.12 у hnswlib 0.8.0 нет
готового колеса, pip собирает его из исходников. Docker и GPU не нужны. Пик памяти одного
сценария около 420 МБ, весь прогон идёт около 5 минут на 4 vCPU.

## Как запустить

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python data.py            # данные и эталон, кэшируются в data_cache.npz
.venv/bin/python hnsw_demo.py all   # или один сценарий: levels, ef_sweep, m_sweep, filter, delete
```

Сборка индекса идёт в 4 потока, поиск в один поток, чтобы латентность запроса не зависела от
числа ядер. Число потоков сборки задаёт константа `BUILD_THREADS` в `hnsw_demo.py`.
