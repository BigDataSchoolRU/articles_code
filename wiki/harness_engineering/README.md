# Harness engineering

Код к статье [Harness engineering](https://bigdataschool.ru/wiki/harness_engineering/).

Одна и та же локальная модель решает одну и ту же задачу двумя способами. `bare.py` отдаёт
модели заготовку и тесты одним запросом и засчитывает первый ответ. `harness.py` оборачивает
модель в минимальный harness: цикл шагов, инструменты чтения и прогона тестов, песочницу,
автоматическую проверку тестами после каждой правки и детектор повторов кода. Задача
одинаковая: реализовать `parse_duration("1h 30m") -> 5400` так, чтобы прошли 13 тестов.

## Состав

| Файл | Что внутри |
|---|---|
| `bare.py` | голая модель: один вызов `/api/chat`, код из ответа, один прогон тестов для оценки |
| `harness.py` | минимальный harness: цикл до 8 шагов, инструменты `read_file` и `run_tests`, правка блоком кода в тексте, песочница во временной папке, проверка тестами, детектор петли, `progress.md` |
| `task/duration.py` | заготовка функции с описанием формата в docstring |
| `task/test_duration.py` | 13 тестов `unittest`, агенту их менять нельзя |
| `docker-compose.yml` | Ollama в Docker, если она не установлена локально |
| `RUNBOOK.md` | пошаговая инструкция с ожидаемым выводом и разбором типовых граблей |

## Окружение

Python 3.12, только стандартная библиотека. Ollama 0.40.13, модели `qwen2.5:7b` и
`llama3.1:8b` (около 10 ГБ на диске). Прогнано на Ubuntu 24.04 x86_64, 4 vCPU без GPU, Ollama в
Docker. На CPU один шаг модели идёт от 30 секунд до 9 минут, полный прогон harness на одной
модели около 15-35 минут.

## Как запустить

```bash
ollama pull qwen2.5:7b
python3 bare.py qwen2.5:7b
python3 harness.py qwen2.5:7b
# сырые ответы модели по шагам в jsonl
TRACE=trace.jsonl python3 harness.py qwen2.5:7b
```

Подробности по шагам, ожидаемый вывод и что делать, если пошло не так, в
[RUNBOOK.md](RUNBOOK.md).
