# RUNBOOK: как повторить демо к статье про мультимодальный ИИ

Демо показывает две вещи: изображение внутри модели превращается в токены, и
число этих токенов зависит от разрешения картинки, а не от её смысла.

## Окружение

- Python 3.12
- Ollama 0.32.13 или новее, доступна по адресу http://localhost:11434
- Модель qwen2.5vl:7b, около 6 ГБ на диске
- Python-пакеты: ollama 0.6.2, pillow 12.3.0
- Оперативной памяти под модель нужно порядка 8 ГБ свободных

## Шаг 1. Проверяем, что Ollama жива

```bash
ollama --version
curl -s -m 5 http://localhost:11434/api/tags | head -c 80
```

В выводе должна быть версия и JSON со списком моделей. Если ответа нет, Ollama
не запущена: поднимите её командой `ollama serve` в отдельном окне терминала.

## Шаг 2. Скачиваем мультимодальную модель

```bash
ollama pull qwen2.5vl:7b
```

Загрузка около 6 ГБ, на среднем канале это десять минут. Успех виден по строке
`success` в конце и по появлению модели в выводе `ollama list`.

## Шаг 3. Ставим зависимости

```bash
python3 -m pip install "ollama==0.6.2" "pillow==12.3.0"
```

Проверка: `python3 -c "import ollama, PIL; print('ok')"` печатает ok.

## Шаг 4. Готовим тестовую картинку

```bash
python3 make_sample.py
```

Рядом появится файл sales_table.png с таблицей продаж по кварталам. Мы знаем
правильные ответы заранее, поэтому легко проверить, что модель прочитала именно
их, а не придумала.

## Шаг 5. Смотрим, во сколько токенов обходится картинка

```bash
python3 image_to_tokens.py
```

Скрипт подаёт одну и ту же таблицу в трёх разрешениях и печатает
prompt_eval_count, то есть длину промпта после того, как картинка превратилась в
токены. Текст вопроса не меняется, поэтому весь прирост даёт изображение. Шаг
прошёл, если по трём строкам вывода число токенов растёт вместе с разрешением.

## Шаг 6. Сравниваем картинку и текст на одной модели

```bash
python3 text_vs_image.py
```

Одна и та же таблица уходит сначала изображением, потом обычным текстом. Шаг
прошёл, если оба ответа по смыслу совпадают, а токенов у картинки заметно
больше.

## Если не так

- **Ответ пустой или про другое.** Убедитесь, что подаётся именно
  qwen2.5vl:7b: обычная текстовая модель картинку молча проигнорирует.
- **Первый запрос идёт минуту, остальные секунды.** Это нормально: Ollama
  загружает веса модели в память при первом обращении.
- **Модель ошибается в числах на маленькой картинке.** Так и задумано: при
  сильном уменьшении мелкий текст теряется ещё до попадания в визуальный
  энкодер. Разрешение здесь важнее размера модели.
- **Не хватает памяти.** Закройте тяжёлые приложения или возьмите модель
  поменьше, например qwen2.5vl:3b.
