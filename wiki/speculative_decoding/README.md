# Speculative decoding

Код к статье [Speculative decoding](https://bigdataschool.ru/wiki/speculative_decoding/).

Замер speculative decoding (спекулятивного декодирования) в `llama-server` из llama.cpp на CPU.
Целевая модель Qwen2.5-7B-Instruct (Q4_K_M) генерирует один и тот же ответ на два промпта в пяти
конфигурациях: без спекуляции, с draft-моделью Qwen2.5-0.5B-Instruct (q8_0) при длине черновика 3
и 8, с n-gram черновиком `ngram-simple` и `ngram-mod` без второй модели. Промпты нарочно разные:
переписывание кода, где ответ почти целиком повторяет вход, и свободная сказка, где повторять
нечего. По каждому запросу снимаются скорость генерации, доля принятых токенов черновика и sha256
ответа: при `temperature 0` текст со спекуляцией и без неё сравнивается побайтно. `tie_check.py`
разбирает, почему на CPU он всё-таки расходится.

## Состав

| Файл | Что делает |
|---|---|
| `get_llama_cpp.sh` | качает готовый CPU-релиз llama.cpp v0.9.0 (сборка b12110) под Linux x86_64, сверяет sha256, распаковывает в `./llama.cpp` |
| `models.sh` | находит GGUF-файлы `qwen2.5:7b` и `qwen2.5:0.5b-instruct-q8_0` в хранилище Ollama и ставит на них симлинки в `./models` |
| `spec_bench.py` | для каждой конфигурации поднимает `llama-server`, гонит промпты из `prompts/` с `temperature 0`, печатает скорость, приём черновика, sha256 ответа и сводную таблицу. Только стандартная библиотека Python |
| `prompts/code_rewrite.txt` | добавить аннотации типов и docstring к функции на 28 строк, ответ в основном копирует вход |
| `prompts/creative_story.txt` | короткая сказка, ответ ничего не повторяет |
| `tie_check.py` | показывает, почему ответ со спекуляцией разошёлся с baseline при `temperature 0`: один и тот же префикс, прочитанный батчем и по одному токену, даёт разный порядок двух почти равновероятных кандидатов |
| `RUNBOOK.md` | пошаговый прогон с ожидаемым выводом |

## Окружение

Linux x86_64 с AVX2, 4 ядра и 9 ГБ свободной памяти, Python 3.10+, Ollama для скачивания моделей
(около 5.2 ГБ на диске). GPU не нужен.

## Как запустить

```bash
./get_llama_cpp.sh
ollama pull qwen2.5:7b
ollama pull qwen2.5:0.5b-instruct-q8_0
./models.sh
python3 spec_bench.py
python3 tie_check.py
```

Прогон на 4 vCPU без GPU идёт около 35 минут. Ожидаемый вывод целиком приведён в `RUNBOOK.md`.
