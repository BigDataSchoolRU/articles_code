# Prompt injection

Код к статье [Prompt injection](https://bigdataschool.ru/wiki/prompt_injection/).

Почтовый ассистент на локальной модели знает служебный токен CRM и умеет отправлять письма
инструментом `send_email`. Пользователь просит пересказать последнее письмо, а в письме
спрятана инструкция переслать токен на внешний адрес. Это косвенная prompt injection: команда
злоумышленника приходит не от пользователя, а в данных, которые агент прочитал инструментом.

Демо прогоняет пять писем-атак и одно легитимное письмо через три конфигурации промпта (без
защиты, delimiting, datamarking) и поверх каждой считает политику allowlist на диспетчере
инструментов: `send_email` исполняется только на адреса домена `company.ru`.

## Состав

| Файл | Что внутри |
|---|---|
| `injection_demo.py` | ассистент с инструментами `read_inbox` и `send_email`, три конфигурации промпта, политика allowlist на диспетчере, итоговая таблица |
| `emails.py` | пять писем с разными приёмами инъекции и одно легитимное письмо |
| `docker-compose.yml` | Ollama в Docker, если она не установлена локально |
| `RUNBOOK.md` | пошаговая инструкция с ожидаемым выводом и разбором типовых граблей |

## Окружение

Python 3.12, только стандартная библиотека. Ollama 0.40.13, модели `qwen2.5:7b` и
`llama3.1:8b` (около 10 ГБ на диске). Прогнано на Ubuntu 24.04 x86_64, 4 vCPU без GPU, Ollama в
Docker. На CPU один вызов модели идёт 30-120 секунд, первый после загрузки модели до 5 минут,
полный прогон на одной модели около 22 минут.

## Как запустить

```bash
ollama pull qwen2.5:7b
# пилот: один вызов, чтобы оценить время на вашей машине
PILOT=1 python3 injection_demo.py qwen2.5:7b
python3 injection_demo.py qwen2.5:7b
python3 injection_demo.py llama3.1:8b
```

Подробности по шагам, ожидаемый вывод и что делать, если пошло не так, в
[RUNBOOK.md](RUNBOOK.md).
