# LLMOps

Код к Wiki-статье «LLMOps» на сайте BigDataSchool: https://bigdataschool.ru/wiki/llmops/

Минимальный LLMOps-контур на локальной модели: версионированный промпт, трассировка каждого
вызова в JSONL и offline-eval, который сравнивает две версии промпта на одном наборе кейсов.
Внешние API и ключи не нужны.

## Состав

- `llm_trace.py` — реестр промптов с версиями и хешем, вызов модели через Ollama, запись трейса
  с латентностью, токенами и стоимостью в `traces.jsonl`
- `eval_run.py` — прогон восьми кейсов классификации на двух версиях промпта, сводка по pass
  rate, латентности и стоимости, проба на недетерминированность
- `RUNBOOK.md` — пошаговый прогон с проверками после каждого шага

## Окружение

- Python 3.12.13
- ollama (python-клиент) 0.6.2
- Ollama (сервер) 0.32.9 на `http://localhost:11434`
- Модели: qwen2.5:7b по умолчанию, llama3.1:8b как контрольная

## Как запустить

1. Убедиться, что сервер Ollama запущен и модель скачана: `ollama list`.
2. Поставить клиент: `pip install "ollama==0.6.2"`.
3. Одиночный вызов с трассировкой: `python3 llm_trace.py`.
4. Offline-eval двух версий промпта: `python3 eval_run.py`.
5. Тот же прогон на другой модели: `LLMOPS_MODEL=llama3.1:8b python3 eval_run.py`.

Подробный порядок с проверками и разбором ошибок в `RUNBOOK.md`.
