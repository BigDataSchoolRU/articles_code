# Chunking

Код к статье [Chunking](https://bigdataschool.ru/wiki/chunking/).

Два демо показывают, как разбиение документов на чанки меняет поиск в RAG. Корпус это восемь
коротких Markdown-регламентов вымышленной компании на русском языке, с заголовками, списками и
таблицами, и 24 вопроса, у каждого из которых есть эталонная подстрока ответа из корпуса.
Первое демо режет один документ разными сплиттерами LangChain и LlamaIndex и показывает, где
проходят границы и как одни и те же числа `chunk_size` и `chunk_overlap` дают разный результат
в символах и в токенах. Второе индексирует корпус моделью `nomic-embed-text` при разных
стратегиях и размерах чанка и считает hit rate и MRR. LLM в демо не участвует, вывод
воспроизводим.

## Состав

| Файл | Что внутри |
|---|---|
| `corpus/*.md` | восемь регламентов: отпуска, командировки, удалённая работа, информационная безопасность, адаптация, расходы, ДМС, дежурства |
| `questions.jsonl` | 24 вопроса: текст, документ, эталонная подстрока ответа |
| `01_split_compare.py` | один документ, пять сплиттеров: число чанков, длина в символах и токенах, первая граница, метаданные заголовков, умолчания пакетов, окно модели эмбеддингов |
| `02_retrieval_eval.py` | стратегии fixed, recursive, markdown, sentence для размеров 128-1024 токенов плюс semantic и документ целиком: hit@1, hit@3, MRR@10, число разрезанных ответов, цена контекста top-3, время индексации |
| `requirements.txt` | версии пакетов, на которых снят вывод |
| `docker-compose.yml` | Ollama в Docker, если она не установлена локально |
| `RUNBOOK.md` | пошаговая инструкция с ожидаемым выводом и разбором типовых граблей |

## Окружение

Python 3.12, `langchain-text-splitters` 1.1.3, `llama-index-core` 0.14.25,
`llama-index-embeddings-ollama` 0.10.0, `tiktoken` 0.14.0. Ollama 0.40.13, модель эмбеддингов
`nomic-embed-text` (274 МБ, 768 измерений, окно 2048 токенов). Размер чанка задаётся в токенах
кодировки `cl100k_base`. Прогнано на Ubuntu 24.04 x86_64, 4 vCPU без GPU, Ollama в Docker.

## Как запустить

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
ollama pull nomic-embed-text
.venv/bin/python 01_split_compare.py
.venv/bin/python 02_retrieval_eval.py
```

Подробности, ожидаемый вывод и типовые ошибки в [RUNBOOK.md](RUNBOOK.md).
