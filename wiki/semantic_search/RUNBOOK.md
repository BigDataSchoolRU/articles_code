# RUNBOOK: semantic search на Ollama + numpy

Демо показывает разницу между semantic search (поиск по смыслу через эмбеддинги)
и наивным поиском по ключевым словам на маленьком корпусе обращений в
техподдержку.

## Окружение

- Python 3.12
- Пакеты: `ollama` 0.6.2 (клиент), `numpy` 2.5.2
- Локальный сервер Ollama 0.32.13 на `http://localhost:11434` со скачанной
  моделью эмбеддингов `nomic-embed-text` (768 измерений)

Установка:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install ollama numpy

# Ollama: https://ollama.com/download
ollama pull nomic-embed-text
```

## Шаг 1. Проверить, что Ollama доступна и модель на месте

```bash
curl -s http://localhost:11434/api/tags | grep nomic-embed-text
```

Ожидаемый вывод: строка с `"name":"nomic-embed-text:latest"`. Если пусто —
модель не скачана, выполните `ollama pull nomic-embed-text` и повторите.

## Шаг 2. Запустить сравнение

```bash
python3 search_comparison.py
```

Ожидаемый вывод: два ранжированных списка — по cosine similarity эмбеддингов
и по пересечению ключевых слов, — и итоговая строка о том, какой подход нашёл
целевой документ. Пример реального прогона:

```
Semantic search (cosine similarity по эмбеддингам), топ-3:
  0.7660  Не могу зайти в личный кабинет, забыл пароль
  0.7339  Как продлить лицензию на антивирус
  0.7211  Ноутбук зависает при подключении к Wi-Fi в переговорной

Поиск по ключевым словам (пересечение множеств слов), топ-3:
  overlap=0  Не могу зайти в личный кабинет, забыл пароль
  overlap=0  Принтер на третьем этаже не печатает цветные документы
  overlap=0  Как получить доступ к общей папке проекта X

Semantic search нашёл его первым: True
Keyword search: пересечений слов нет ни с одним документом — ранжировать нечем, результат недостоверен
```

Semantic search находит нужный документ, потому что сравнивает смысл
(«кодовая фраза» ≈ «пароль», «профиль на сайте» ≈ «личный кабинет»), а не
буквы. Поиск по ключевым словам не находит ни одного пересечения и не может
ранжировать корпус вообще.

## Если не так

- **`ConnectionError` / таймаут при вызове `ollama.embeddings`.** Ollama не
  запущена. Запустите `ollama serve` и повторите.
- **Модель не найдена (`model not found`).** Модель не скачана в этот
  инстанс Ollama: `ollama pull nomic-embed-text`.
- **Semantic search и keyword search дают похожий (не нулевой) результат
  на своём запросе.** Значит формулировка запроса случайно пересеклась
  словами с корпусом — замените корпус или запрос, это не баг модели.
- **Косинусные близости у всех документов почти одинаковые (стянуты в узкий
  диапазон вроде 0.73-0.76, различия только в третьем знаке после запятой,
  и лидирует случайный документ).** Забыт префикс задачи `search_query: ` /
  `search_document: ` — nomic-embed-text асимметричная модель, без префикса
  similarity считается некорректно.
