# RUNBOOK: векторный поиск в Qdrant с фильтрацией по payload

Пошаговый прогон демо к Wiki-статье «Qdrant». Всё поднимается локально, внешние сервисы не нужны.

## Окружение

| Компонент | Версия |
|---|---|
| Qdrant (Docker) | 1.19.0 |
| qdrant-client (Python) | 1.19.0 |
| Python | 3.12.13 |
| Ollama | 0.32.13 |
| Модель эмбеддингов | nomic-embed-text, 768 измерений |
| Docker Engine | 29.7.2 |

Что должно быть доступно: демон Docker, Ollama на http://localhost:11434, свободные порты 6333 и 6334.

## Шаг 1. Поднять Qdrant

```bash
docker compose up -d
curl -s http://localhost:6333/
```

Что должно быть в выводе: JSON с полями title и version, версия 1.19.0. Готовность шардов проверяется
запросом `curl -s http://localhost:6333/readyz`, ответ `all shards are ready`. Панель управления
открывается на http://localhost:6333/dashboard.

## Шаг 2. Проверить модель эмбеддингов

```bash
ollama list | grep nomic-embed-text
curl -s http://localhost:11434/api/embeddings -d '{"model":"nomic-embed-text","prompt":"тест"}' | head -c 80
```

Что должно быть в выводе: строка с моделью и начало массива чисел. Если модели нет, скачайте её
командой `ollama pull nomic-embed-text`.

## Шаг 3. Поставить клиент

```bash
python3 -m pip install "qdrant-client==1.19.0"
```

Что должно быть в выводе: успешная установка, `pip show qdrant-client` печатает версию 1.19.0.

## Шаг 4. Прогнать демо

```bash
python3 qdrant_demo.py
```

Что должно быть в выводе: размерность вектора 768, восемь загруженных точек, три результата поиска
без фильтра и три результата с фильтром по полю topic. Последними строками печатается статус
коллекции green, порог индексации 10000 КБ и схема индексов по payload.

## Шаг 5. Погасить стенд

```bash
docker compose down
```

Данные лежат в именованном томе и переживают перезапуск. Полная очистка делается командой
`docker compose down -v`.

## Если не так

- Ответ `Connection refused` на порт 6333 означает, что контейнер ещё поднимается. Подождите
  несколько секунд и повторите запрос к корню API.
- Ответ `Connection refused` на порт 11434 означает, что Ollama не запущена. Запустите её командой
  `ollama serve` в отдельном терминале.
- Поле indexed_vectors_count равно нулю на маленькой коллекции, и это штатное поведение. Пока объём
  сегмента ниже порога indexing_threshold, Qdrant ищет полным перебором, потому что так быстрее.
- Ошибка про несовпадение размерности вектора означает, что коллекция создана под другую модель
  эмбеддингов. Удалите коллекцию и создайте заново.
