# RUNBOOK: цикл ReAct на LangGraph/LangChain и локальной модели

## Окружение

- Python 3.12
- Пакеты: `langchain` 1.3.15, `langchain-core` 1.5.4, `langgraph` 1.2.11, `langchain-ollama` 1.1.0
- Ollama 0.32.13, доступна на `http://localhost:11434`, модель `qwen2.5:7b` уже скачана
  (`ollama pull qwen2.5:7b`, ~4.7 ГБ, если модели нет)

Установка пакетов:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install "langchain==1.3.15" "langgraph==1.2.11" "langchain-ollama==1.1.0"
```

## Шаг 1. Проверить, что Ollama жива и модель на месте

```bash
curl -s -m 5 http://localhost:11434/api/tags | grep -o '"qwen2.5:7b"'
```

Должно вывести `"qwen2.5:7b"`. Если пусто — модель не скачана, `ollama pull qwen2.5:7b` (~4.7 ГБ).

## Шаг 2. Запустить демо ReAct-агента

```bash
python3 react_agent_demo.py
```

Что должно быть в выводе: блок `=== Полный трейс цикла ReAct ===` со строками `Thought:`
(модель объясняет, зачем вызывает инструмент), `Action:` (вызов инструмента `word_length` с
аргументом) и `Observation:` (результат инструмента), затем `=== Финальный ответ ===`
с текстовым ответом. Модель обязана вызвать инструмент дважды (по разу на каждое слово) — если
в трейсе меньше двух вызовов `Action`, значит модель начала гадать без инструмента, шаг не
прошёл.

Прогон занимает 15-25 секунд на CPU (два обращения к `qwen2.5:7b`).

## Шаг 3. Проверить факт устаревания `create_react_agent`

```bash
python3 create_react_agent_deprecation_check.py
```

Что должно быть в выводе: `категория: LangGraphDeprecatedSinceV10` и текст предупреждения,
объясняющий перенос функции в `langchain.agents.create_agent`. Скрипт не обращается к модели,
выполняется мгновенно.

## Если не так

- **`ConnectionError` / `ollama api: НЕДОСТУПНА`** — Ollama не запущена. Поднять: `ollama serve`
  (или запустить приложение Ollama), проверить `curl -s http://localhost:11434/api/tags`.
- **Модель отвечает не по-русски или мимо темы** — `qwen2.5:7b` иногда переключается на
  английский при низкой температуре промпта; в скрипте уже стоит `temperature=0` и явная
  инструкция на русском, повторный запуск обычно решает проблему без правки кода.
- **В трейсе только один вызов инструмента** — модель посчитала, что уже знает ответ. Это
  штатное поведение LLM без принуждения, а не баг демо: попробуйте более длинный или менее
  очевидный вопрос.
- **`create_react_agent_deprecation_check.py` не показывает предупреждение** — значит
  установлена версия LangGraph, где функцию уже удалили (после V2.0) или ещё не пометили
  устаревшей (до V1.0). Сверьте версию `langgraph` командой `pip show langgraph`.
