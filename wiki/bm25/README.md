# BM25

Код к статье [BM25](https://bigdataschool.ru/wiki/bm25/).

BM25 это функция ранжирования для полнотекстового поиска: по каждому слову запроса она
складывает вес редкости слова (IDF), насыщающуюся частоту слова в документе (параметр `k1`) и
поправку на длину документа (параметр `b`). Демо считает BM25 руками и сверяет с тремя
реализациями (rank-bm25, bm25s, `bm25()` в SQLite FTS5), показывает, как `k1` и `b` меняют
порядок выдачи, и что делает с русским текстом стемминг. Корпус: 16 коротких документов
по дата-инженерии на русском.

## Состав

| Файл | Что делает |
|---|---|
| `requirements.txt` | `rank-bm25==0.2.2`, `bm25s==0.3.16`, `PyStemmer==3.1.0`, `numpy==2.5.4` |
| `corpus.py` | 16 документов (заголовок и текст), 4 запроса, общий токенизатор |
| `01_formula_by_hand.py` | BM25 по формуле на чистом Python, сверка с `rank_bm25.BM25Okapi` и `bm25s` (`lucene`, `robertson`), разбор одной оценки по словам, три варианта IDF на одном запросе |
| `02_k1_b_effect.py` | насыщение частоты при разных `k1` и сетка `k1` x `b`: где длинный документ с повторами обгоняет короткий и где уступает |
| `03_russian_stemming.py` | bm25s без стемминга и со стеммером Snowball russian из PyStemmer |
| `04_sqlite_fts5.py` | `bm25()` в SQLite FTS5: знак, сверка с формулой из исходника, `OR` против пробела, веса колонок |
| `RUNBOOK.md` | пошаговый прогон с ожидаемым выводом |

## Окружение

Python 3.12 или новее (этого требует numpy 2.5.4), модуль `sqlite3`, собранный с FTS5
(проверено на системном Python 3.12.3 в Ubuntu 24.04, SQLite 3.45.1). Docker, GPU и внешние сервисы не нужны. venv занимает около 90 МБ,
каждый скрипт идёт меньше секунды.

## Как запустить

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python 01_formula_by_hand.py
.venv/bin/python 02_k1_b_effect.py
.venv/bin/python 03_russian_stemming.py
.venv/bin/python 04_sqlite_fts5.py
```

Скрипты запускаются из этой папки: они импортируют `corpus.py` рядом с собой.
