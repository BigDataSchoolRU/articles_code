# articles_code

handbook: v0.1

Вся информация здесь выложена для свободного доступа к коду, использованному в написании статей, и для
доказательства концепций.

Если вам пригодился код, поставьте лайк — ну что вам стоит, это дает нам мотивацию сопротивляться
засилью Искусственного Интеллекта SkyNet.

## Что где

| Каталог | Что |
|---|---|
| [`wiki/`](wiki/) | код к статьям энциклопедии bigdataschool.ru/wiki: `wiki/<slug>/` с README и RUNBOOK, оглавление — [`wiki/README.md`](wiki/README.md) |
| `airflow_course/` | код к урокам курса по Apache Airflow |
| `openrouter/` | серия статей про OpenRouter |
| `starrocks_articles/` | статьи про StarRocks |
| `wiki_apache_arrow/`, `wiki_ksqldb/`, `wiki_polars/` | код ранних Wiki-статей, до раскладки `wiki/<slug>/` |
| файлы в корне | код ранних статей блога; на них ведут ссылки из статей, поэтому они не переносятся |

Как запустить конкретное демо — в `RUNBOOK.md` его каталога.
