# ADR 0001. Облегчённый стандарт для публичного демо-кода

- Статус: принято
- Дата: 2026-10-04

## Контекст

Репо публичный, на его файлы ссылаются опубликованные статьи bigdataschool.ru и курсы («весь код,
используемый в статье, выкладываем на наш GitHub»). Код — это иллюстрация к тексту статьи, а не
сервис: он не деплоится и не работает по расписанию.

## Решение

Handbook v0.1 применяется облегчённо. Сознательные отклонения от `compliance/checklist.md`:

| Пункт | Отклонение | Почему |
|---|---|---|
| C15 | `edge_v4.py` и другие файлы в корне не переименовываются и не переносятся | на них ссылаются опубликованные статьи (например, Edge Computing); переименование ломает ссылки |
| C16 | нет `deploy/*.env.example` | демо читают env-переменные, которые описаны в RUNBOOK каждого `wiki/<slug>/`; деплоя нет |
| C21 | демо-скрипты не правятся под `set -euo pipefail` | скрипт должен совпадать с текстом статьи, где он приведён |
| C23–C25 | — | задач по расписанию нет |

Код опубликованных статей правится только вместе с текстом статьи.

## Последствия

Аудит ниже 90 % — это ожидаемо и закрыто этим ADR. Новые демо (`wiki/<slug>/`) пишутся по правилам
стадии wiki-code плагина bds-wiki и проверяются `ops/selfcheck.sh` и CI.
