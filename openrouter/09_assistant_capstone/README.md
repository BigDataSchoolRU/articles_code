# Капстоун: дешёвый мультимодальный ассистент на русских эмбеддингах

Код к статье «Капстоун: дешёвый мультимодальный ассистент на русских эмбеддингах» на сайте BigDataSchool: (URL появится после публикации)

## Состав
- `assistant.py` - RAG на русскоязычных эмбеддингах (`baai/bge-m3`) плюс зрение, с замерами стоимости и времени.
- `RUNBOOK.md` - пошаговый прогон с проверками.

## Окружение
Python 3.12, пакет `httpx`. Ключ OpenRouter в переменной окружения `OPENROUTER_API_KEY`. Запуск генерирует картинку, это платный вызов.

## Как запустить
1. Установить зависимости: `pip install httpx`.
2. Экспортировать ключ: `export OPENROUTER_API_KEY="sk-or-v1-ваш_ключ"`.
3. Запустить `python3 assistant.py`.
